# GNSS files of the Titan 2 factory firmware (Android 14) for the native vendor chroot: the MediaTek
# navigation daemon mnld (OpenRC t2-mnld), the SUPL daemon mtk_agpsd (optional), gps_dump and
# the legacy GPS HAL module gps.default.so that t2-gnssd loads in-process (bionic_translation).
# SELF-SUFFICIENT: the complete DT_NEEDED closure of the four binaries (needed-closure.py of titan2-vendor-runtime,
# 2026-11-11) plus the bionic linker and the property tools t2-vendor-env uses, so
#   t2-vendor-setup SRC [DEST] /usr/share/titan2-vendor-runtime/files.d/gnss.txt
# alone gives a root mnld links in ("CANNOT LINK EXECUTABLE ... libhidlbase.so not found" was the
# earlier pruned list that relied on the vendor-container list). Data lines carry NO trailing
# comments: t2-vendor-setup takes the rest of the line as the destination. Shared with
# the fingerprint list (same destination, copied twice harmlessly): linker64, libapexsupport, libbase,
# libbinder, libc, libc++, libcrypto, libcutils, libdl, libdl_android, liblog, libm, libutils,
# libvndksupport, libz.
# The AIDL service android.hardware.gnss-service.mediatek is NOT needed (no binder path).
#   <source below system_a / system_ext_a / vendor_a>   <path below the vendor root>
# bionic runtime: the linker (PT_INTERP /system/bin/linker64 of every vendor binary)
